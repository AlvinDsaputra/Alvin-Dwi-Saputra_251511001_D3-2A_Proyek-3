Kuasai Dasar Web dengan HTML5 & CSS3 Murni

Bangun fondasi pengembangan web yang kuat, semantik, dan responsif tanpa bergantung pada framework. Pelajari konsep dasarnya secara langsung.

Daftar Lokakarya

Apa yang Akan Kamu Pelajari?

HTML Semantik

Memahami anatomi dokumen, hierarki heading, serta pemilihan tag yang bermakna untuk aksesibilitas dan SEO.

CSS & Flexbox

Menguasai Box Model, Custom Properties (CSS Variables), Specificity, serta penataan layout dengan Flexbox.

Desain Responsif

Merancang tampilan berpendekatan Mobile-First agar layout beradaptasi rapi di layar 320px hingga desktop.

Mengapa Harus Ikut Program Ini?

Pelatihan ini dirancang khusus untuk mahasiswa D3 Teknik Informatika guna memberikan pemahaman mendalam sebelum mempelajari framework modern seperti Bootstrap, Tailwind, atau React.

  • Praktik Langsung: Menulis kode dari nol menggunakan VS Code & Live Server.
  • Pengujian DevTools: Belajar melakukan diagnosis layout dan validasi W3C.
  • Review & Mentoring: Dapatkan masukan langsung dari tim dosen dan asisten praktikum.
